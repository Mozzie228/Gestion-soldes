Guide d'utilisation

  1. Ouvrir l'application : gardez le fichier HTML sur votre ordinateur et ouvrez-le avec Chrome, Firefox ou Edge. Internet n'est pas nécessaire.
  2. Saisir une journée : ouvrez « Saisie quotidienne », choisissez la date, entrez les soldes de début et de fin et la commission de chaque service, puis indiquez les espèces réellement restantes en caisse à la fin de la journée.
  3. Mode manuel : les commissions ne sont pas calculées avec les taux de 0,5 %. Entrez le montant communiqué par l'opérateur ou calculé dans votre relevé. Les totaux sont additionnés automatiquement.
  4. Enregistrer : cliquez sur « Enregistrer la journée ». Les données sont enregistrées localement dans le navigateur. Une deuxième saisie pour la même date remplace la première après confirmation.
  5. Consulter / modifier : dans « Historique », filtrez par date ou période. Cliquez sur « Modifier » pour charger une journée dans le formulaire, ou « Supprimer » pour retirer cette journée.
  6. Faire l’inventaire : le tableau de bord additionne les soldes de fin des quatre opérateurs et les espèces restantes saisies pour la dernière journée enregistrée. Vérifiez que les espèces ne sont pas déjà comptées dans les soldes des opérateurs.
  7. Comprendre les commissions : « du jour » correspond à la date du jour ; « du mois » additionne les commissions du mois en cours ; « cumulées » additionne toutes les saisies conservées.
  8. Fonds de base : dans le tableau de bord, entrez votre capital initial et enregistrez-le. « Fonds de base + commissions cumulées » est une estimation, pas nécessairement l’argent disponible si les commissions sont déjà comprises dans les soldes.
  9. Sauvegarder : dans « Sauvegarde », exportez le fichier JSON régulièrement. Pour transférer les données sur un autre appareil, copiez ce fichier puis importez-le depuis l'autre appareil.
  10. CSV : l'export CSV peut être ouvert dans Excel pour analyser l'historique.

Conseils importants

  • Vérifiez les montants avant l'enregistrement.
  • Une sauvegarde locale n'est pas une synchronisation en ligne : chaque appareil possède ses propres données.
  • Ne supprimez pas le fichier HTML si vous n'avez pas une copie. Le stockage du navigateur peut être effacé par les réglages de l'appareil.
  • Pour utiliser plusieurs appareils, exportez et importez les données manuellement. Évitez les saisies concurrentes puis l'importation de sauvegardes différentes, car cela peut écraser des données.
